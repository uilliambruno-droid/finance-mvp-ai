# Pitch Script (3 Minutes)

## 1) Problem
Users need practical financial guidance that is easy to understand and immediately actionable.

## 2) Solution
Pluto combines structured profile intake, contextual memory, and grounded LLM responses to deliver consultant-style guidance.

## 3) Demo Flow
1. Complete profile intake.
2. Ask a planning question.
3. Log an expense in natural language.
4. Upload a CSV and show dashboard updates.
5. Receive context-aware guidance with risk notes.

## 4) Differentiators
- Profile-first personalization.
- Safety-oriented post validation.
- Provider fallback for resilience.
- Event logging for measurable improvement.

## 5) Technical Walkthrough (Optional Add-On)
1. Explain modular architecture (`ui_*`, `state`, `profile`, `llm`, `context_builder`).
2. Explain why OpenRouter is primary and fallback exists.
3. Explain persistence strategy and state restoration.
4. Explain transaction parsing strategy and safeguards.

## 6) Closing
- Pluto is ready for live demo usage and iterative product hardening.
- Next steps: stronger observability, richer analytics, and expanded financial scenarios.
